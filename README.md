# Планировщик

Личный планировщик дня для Android 10 и новее: дела на день, повторы, фото, типовые дела, сигналы, статистика и виджет. Интерфейс на русском, время в 24-часовом формате. Все данные хранятся только на телефоне: у приложения нет аккаунтов, синхронизации и разрешения на интернет.

## Как скачать APK

1. Войдите в GitHub и откройте вкладку **Actions** этого репозитория, слева выберите **Сборка APK**.
2. Откройте последний зелёный запуск на ветке `main`.
3. Внизу страницы, в разделе **Artifacts**, скачайте `planner-apk-<номер>`. Это ZIP; внутри лежит `app-debug.apk`.

Архивы хранятся 90 дней. Чтобы собрать свежий, на странице **Сборка APK** нажмите **Run workflow**.

## Как установить

1. Откройте `app-debug.apk` на телефоне. Если Android спросит, разрешите установку из этого источника (браузера или файлового менеджера).
2. Обновление ставьте **поверх** прежней версии, не удаляя её: дела и фото сохранятся. Все сборки подписаны одним ключом, номер версии растёт с каждой сборкой.
3. Не удаляйте приложение: вместе с ним сотрутся все данные. Перед обновлением сделайте резервную копию.

## Как добавить виджет

Долго нажмите на свободное место рабочего стола → **Виджеты** → **Планировщик** → перетащите на экран. Размер можно менять, длинный список прокручивается. Нажатие на дату открывает сегодняшний день, на строку — страницу дела, на **+** — новое дело на сегодня.

## Как переключить стиль оформления

На экране дня нажмите шестерёнку → **Стиль оформления** → **Обычный** или **С эффектами**. Выбор сохраняется. Светлая или тёмная тема берётся из настроек системы. Если в системе отключены анимации, конфетти и похвала не показываются.

## Сигналы

У дела со временем можно включить сигнал в начале, у промежутка — ещё и в конце. Тип сигнала: уведомление или будильник на весь экран (звук играет, пока не нажата кнопка «Выключить»).

- При включении сигнала приложение попросит разрешение на уведомления. Если отказать, дела сохраняются, но сигналы не показываются; в редакторе дела и в настройках останется блок с кнопками, как включить разрешения.
- Если окно на весь экран не разрешено (Android 14 и новее), будильник покажет уведомление с кнопкой «Выключить», звук играет до её нажатия.
- Громкость будильника, режим «Не беспокоить» и настройки каналов уведомлений остаются под управлением телефона.
- После перезагрузки сигналы восстанавливаются, когда телефон разблокирован в первый раз.
- Если в настройках Android нажать «Остановить» для приложения, система отменит его сигналы. После этого откройте приложение, и они поставятся заново.
- На некоторых прошивках (Xiaomi, Huawei и подобных) для надёжных сигналов разрешите приложению автозапуск и отключите для него экономию батареи.

## Резервная копия

- **Сделать копию:** шестерёнка → **Резервная копия** → **Сохранить ZIP** → выберите место в системном диалоге. В файл попадают дела, отметки о выполнении, типовые дела и фото. Файл не зашифрован, храните его как личный.
- **Восстановить:** **Восстановить из ZIP** → выберите файл → подтвердите. Импорт **полностью заменяет** текущие данные содержимым файла, а не объединяет их. Файл сначала проверяется целиком: повреждённый или чужой файл текущие данные не меняет.
- Выбранный стиль оформления и системные разрешения в копию не входят.

## Ключ подписи

`keystore/debug.keystore` — отладочный ключ, которым подписывается каждая сборка, чтобы новая версия ставилась поверх старой. Он лежит в открытом репозитории и **не предназначен для публикации приложения**. Он не подтверждает происхождение файла, поэтому скачивайте APK только из Actions этого репозитория.

## Для разработки

- Сборка идёт в GitHub Actions (`.github/workflows/build.yml`) при каждом push в `main` и вручную: модульные тесты, сборка APK, проверка готового файла (подпись, пакет, версия, отсутствие разрешения на интернет) и выкладка артефакта. На телефоне сборка не проверяется.
- Локально: `./gradlew testDebugUnitTest assembleDebug` (нужны JDK 17 и Android SDK).
- Идентификатор пакета `ru.dayplanner.app` менять нельзя, иначе обновление не встанет поверх установленной версии.
- Модульные тесты (`app/src/test`) проверяют сортировку списка дня, расчёт повторов, время ближайшего сигнала, метки календаря и статистику.
- Задание, по которому написано приложение: `AGENT_PROMPT.md`.
