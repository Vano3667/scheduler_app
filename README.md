# Планировщик

Планировщик дня для Android (Kotlin, Jetpack Compose). Личное приложение: данные хранятся только на телефоне, без аккаунтов и без доступа в интернет.

Проект в разработке. Подробная инструкция появится по мере готовности этапов.

## Как скачать APK

1. Откройте вкладку **Actions** этого репозитория.
2. Выберите последний успешный (зелёный) запуск «Сборка APK».
3. Внизу страницы, в разделе **Artifacts**, скачайте архив `planner-apk-…` и распакуйте его — внутри лежит файл `app-debug.apk`.

## Ключ подписи

Файл `keystore/debug.keystore` — отладочный ключ, которым подписывается каждая сборка, чтобы новая версия ставилась поверх старой без потери данных. Он лежит в открытом репозитории и **не предназначен для публикации приложения** в магазинах.
