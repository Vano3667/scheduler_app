# Планировщик

Планировщик дня для Android (Kotlin, Jetpack Compose, Material 3). Личное приложение для одного телефона: все данные хранятся только на устройстве, без аккаунтов и без доступа в интернет (разрешения INTERNET у приложения нет).

Требуется Android 10 или новее.

## Как скачать APK

1. Откройте вкладку **Actions** этого репозитория.
2. Выберите последний успешный (зелёный) запуск «Сборка APK».
3. Внизу страницы, в разделе **Artifacts**, скачайте архив `planner-apk-…` и распакуйте его — внутри лежит файл `app-debug.apk`.

Скачивать артефакты можно только войдя в свой аккаунт GitHub. Архивы хранятся 90 дней; чтобы получить свежий, откройте workflow «Сборка APK» и нажмите **Run workflow**.

## Как установить

1. Перенесите `app-debug.apk` на телефон (или скачайте архив прямо с телефона).
2. Откройте файл. Если Android спросит, разрешите установку из этого источника (браузер или файловый менеджер).
3. Новая версия ставится поверх старой, дела и фото сохраняются: все сборки подписаны одним ключом, а номер версии растёт с каждой сборкой.

Не удаляйте приложение перед обновлением — при удалении данные стираются. Перед крупным обновлением на всякий случай сделайте резервную копию.

## Как добавить виджет

1. Долго нажмите на свободное место рабочего стола и выберите «Виджеты».
2. Найдите «Планировщик» и перетащите виджет на экран. Размер можно менять, длинный список прокручивается.
3. Нажатие на дело открывает его страницу, на дату в заголовке — экран дня, на «+» — добавление дела на сегодня.

## Как переключить стиль оформления

На экране дня нажмите значок настроек (шестерёнка) → «Стиль оформления» → «Обычный» или «С эффектами». Выбор сохраняется между запусками. Светлая и тёмная тема выбираются автоматически по настройке системы.

Эффекты (конфетти, похвала, вспышки при нажатии) не показываются, если в системе отключены анимации.

## Сигналы

У дела со временем можно включить сигнал в начале, а у дела с промежутком — ещё и в конце. Тип сигнала: обычное уведомление или «Будильник на весь экран» (звук играет, пока не нажата кнопка «Выключить»).

- При первом включении сигнала приложение попросит разрешение на уведомления. Если отказать, приложение продолжит работать, а в редакторе дела и в настройках останется подсказка, как включить разрешение.
- На Android 14 и новее для окна будильника на весь экран может понадобиться отдельное разрешение — кнопка для него появляется там же. Без него вместо окна будет громкое уведомление с кнопкой «Выключить».
- Сигналы восстанавливаются после перезагрузки телефона, смены времени и часового пояса, обновления приложения и импорта копии.
- После перезагрузки сигналы восстанавливаются, когда телефон разблокирован первый раз.
- Если в настройках Android нажать «Остановить» для приложения, система отменит его сигналы; после этого просто откройте приложение.
- На некоторых прошивках (Xiaomi, Huawei и подобных) для надёжной работы сигналов стоит разрешить приложению автозапуск и отключить для него экономию батареи.

## Резервная копия

**Сделать копию:** Настройки → «Резервная копия» → «Сохранить ZIP» → выберите место в системном диалоге. В одном ZIP-файле сохраняются все дела, отметки о выполнении, типовые дела и фото.

**Восстановить:** Настройки → «Резервная копия» → «Восстановить из ZIP» → выберите файл и подтвердите. Импорт **полностью заменяет** текущие данные содержимым файла. Файл сначала проверяется целиком: повреждённый или чужой файл текущие данные не меняет.

## Ключ подписи

Файл `keystore/debug.keystore` — отладочный ключ, которым подписывается каждая сборка, чтобы новая версия ставилась поверх старой без потери данных. Он лежит в открытом репозитории и **не предназначен для публикации приложения** в магазинах.

## Для разработки

- Сборка идёт в GitHub Actions (`.github/workflows/build.yml`): при каждом push в `main` и вручную. Workflow прогоняет модульные тесты, собирает APK и выкладывает его артефактом.
- Локально: `./gradlew testDebugUnitTest assembleDebug` (нужны JDK 17 и Android SDK).
- Идентификатор пакета `ru.dayplanner.app` менять нельзя: иначе обновление не встанет поверх установленной версии.
- Модульные тесты (`app/src/test`) проверяют сортировку списка дня, расчёт повторов, время ближайшего сигнала, метки календаря и подсчёт статистики.
- Задание, по которому написано приложение: `AGENT_PROMPT.md`.
